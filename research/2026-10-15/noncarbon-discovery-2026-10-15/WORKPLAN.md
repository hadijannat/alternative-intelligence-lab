# Non-carbon compound discovery search

User request: use 1,000 agents to find a novel compound for non-carbon-based intelligent life.

Execution constraint: the tool interface reports 51 concurrent slots including the coordinator. This does not establish that 1,000 sequential agents are impossible. The completed bounded pass uses 24 actual subagents (15 direct specialists and nine child audits) plus a reproducible 1,000-record materials screen; the requested 1,000-agent execution was not performed. Candidate records are not agents, and known database materials are not novel compounds. The named participation ledger is verification/agents.json.

Scope: this new folder and an independent review receipt. Prior work remains unchanged; the preceding RNA investigation has been explicitly checkpointed at the user pivot. No physical synthesis, external correspondence, publication, paid computation or unsupported quantum calculation. Use public primary sources and existing local artifacts. Runtime reasoning settings cannot be inspected; no change is claimed.

Completion for this bounded search means an evidence-based candidate assessment, reproducible data screen, source/novelty audit, and explicit negative/unknown conclusions. Finding a living or intelligent substance is not guaranteed.

| Requirement | Evidence |
|---|---|
| Cover non-carbon chemistry | Independent POM, oxide-memory, inorganic-compartment, sulfide/mineral and alternative-scaffold dossiers |
| Screen1,000 candidates | Primary open database, fixed composition/ID-only selection before property-based screening, raw/screened records, hashes, exclusions and replay |
| Investigate a novel compound | Exact composition proposal if defensible, formal-charge check, structural and prior-art audit; distinguish unreported formula from established novelty |
| Connect functions realistically | Same-condition compatibility matrix for renewal, retention, energy coupling, physical memory and functional inheritance |
| Preserve negative evidence | Carbon-dependent architectures, incompatible media, missing raw data, failed or unmeasured functional gates retained |
| Verify and deliver | Independent numerical/data/claim audit, report, figure/table, source ledger, checks and reproducibility commands |

Selection must never turn formation energy, bandgap, ionic mobility or memory into a probability of life/intelligence. No candidate passes an integrated-life or intelligence gate without direct evidence for those functions. A chemically plausible nominal formula is only a synthesis/structure hypothesis. Lack of an indexed exact-formula hit cannot establish global scientific or patent novelty.

Workers own disjoint subdirectories and preserve each other's work. Expanded review covers crystal coordinates, redox compatibility, inorganic structural transmission, existing repository failures, parent-model replay and physical learning. The independent reviewer owns verification/; root owns this plan, candidate.json, the integrated REPORT.md, progress.md and checks.md. No changes are required to prior callers, models, tests, package dependencies or exports because this is a separate research dossier and inventory.
