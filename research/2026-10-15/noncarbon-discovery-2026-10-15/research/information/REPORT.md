# Information and physical-learning audit

Review date: 2026-10-15. Scope: four positive experimental comparators and one mechanical counterexample, checked against the [memory review](../memory/REPORT.md) and [critical review](../critical/REPORT.md). This review did not make a new compound or run a learning experiment.

**Finding:** inorganic matter supports retained states, chemical response plasticity and engineered physical learning. A lack of demonstrated life in the proposed Mo–W–V composition is an evidence gap, not an impossibility theorem. Memory, learning, self-maintenance and hereditary renewal are distinct claims; one should not require reproduction to acknowledge a learning device, or infer reproduction from a learning device.

An external energy source or experimenter-selected stimulus does not automatically invalidate physical learning. The relevant boundary is where the adaptive state is stored, where its update is computed, and whether the external apparatus supplies the answer during evaluation. An external controller may present training labels while updates remain local to the material system. Conversely, fitting a software readout to a fixed material's responses shows a useful physical feature transform, but does not by itself establish that the material learned.

## Strongest bounded comparators

| System | Positive evidence | Controller and material boundary | Renewal / inherited function |
|---|---|---|---|
| **WO3 / phosphosilicate glass / PdHx** | Reversible protonic conductance programming in an inorganic active stack, including 5 ns pulses under extreme imposed fields. | Fabricated contacts and electrolyte set the ion/electron pathways. Pulse programming changes the material state; a complete learning task and autonomous chemical maintenance are not demonstrated by this component paper. Carbon-containing process materials must be distinguished from the operating active stack. | No replacement of the state-bearing solid or parent-to-new-material transmission demonstrated. |
| **VO2 structural history** | A written history remains accessible through switching-incubation time beyond 10,000 s. This is a stronger memory control than a single hysteresis curve. | Electrical/thermal pulses write the state; the material retains history between pulses, without an external computer continuously rewriting it. The subsequent read is a driven device measurement. | The same fabricated film is followed. Persistence through renewal or copying is unmeasured. |
| **NiO response plasticity** | Repetition and stimulus spacing change the response; a different stimulus restores or enhances it. This supports the paper's operational nonassociative-learning terminology. | Defect/electronic changes occur in the material under imposed gas or light histories. Main chemical-cycle measurements use 200 °C. The unsupervised clustering example is a separate software simulation inspired by the material. | No maintenance of learned function through newly produced NiO or descendants is shown. |
| **Nonlinear contrastive local learning network** | A 32-pair transistor network physically learns XOR and nonlinear regression. Local analog circuits update capacitor-stored gate voltages. | A computer presents inputs/labels, measures and enables/freezes learning; it does not compute each weight update. This is genuine engineered physical learning. The whole component/packaging bill is not established carbon-free. | Gate-voltage storage has poor long-time fidelity; retraining after disturbance is not self-renewal or transmission into newly built networks. |

Primary sources: [Onen et al., Science 2022](https://doi.org/10.1126/science.abp8064); [Samizadeh Nikoo et al., Nature Electronics 2022](https://doi.org/10.1038/s41928-022-00812-z), with [author manuscript](https://infoscience.epfl.ch/record/296085/files/Glass_like_electronics_VO2.pdf); [Zhang et al., PNAS 2021](https://doi.org/10.1073/pnas.2017239118); [Dillavou et al., PNAS 2024](https://doi.org/10.1073/pnas.2319718121). These are measured component or network behaviors, not results for the proposed Mo34WV cluster.

The mechanical alternative deserves the same audit. Li and Mao's 2024 demonstration uses Agilus30 rubber-like printed structures; a computer supplies the adjoint-force calculation and multiplication. Gradients are experimentally measured, while stiffness updates are numerical; this is not an observed all-inorganic, physically self-updating material. It is useful algorithmic/experimental progress, with a clearly bounded claim. [Primary paper, Fig. 1 and Discussion](https://www.nature.com/articles/s41467-024-54849-z).

## Minimal falsifiable assay decision table

These are proposed comparisons, not completed assays. Acceptance tolerances must come from measurement uncertainty and a frozen task specification, not an invented universal life score. They can be tested independently; the table is not a mandatory ladder for every meaning of intelligence.

| Claim | Decisive comparison | Result that retains a narrower conclusion |
|---|---|---|
| **State retention** | Write different histories; match present inputs and measured bulk composition; wait; use a fixed readout on blinded samples. Include unwritten and reset samples. | History separation explained entirely by current temperature, feed or apparatus state: ordinary response, not identified retained material state. |
| **Physical adaptation** | Record internal state updates and task performance; disable or scramble only the update pathway while matching input/energy histories. Freeze readout training before unseen evaluation conditions. | Only software readout training improves performance: useful substrate/readout system, with material learning unestablished. |
| **Adaptive use of memory** | Erase or exchange the proposed stored state while preserving the sensor and action pathways. Test an unseen input relation against matched open-loop and state-independent controls. | Performance survives memory intervention unchanged: retained state is not established as the cause of task improvement. |
| **Self-maintenance** | Track species, activity and energy/material flows through controlled turnover; interrupt the proposed internal repair coupling while retaining comparable resource supply. | Fresh externally manufactured replacements account for function: externally maintained operation. External resources alone do not fail this assay. |
| **Functional inheritance** | Distinguish founder material from new material; compare different parent states under a common feed across transfer, against carryover-only and no-parent controls. Assay the new fraction's specific function. | Original seed persistence, equilibrium convergence or reporter accumulation explains the difference: retention/assembly remains supported, inheritance does not. |
| **Bounded intelligence claim** | Specify tasks, unseen challenges and matched baselines; test causal sensing–state–action coupling and adaptation. Report the demonstrated task range and dependence on an external optimizer. | A single response curve or lookup-like task supports that narrow function only; broad intelligence remains untested. |

For the Mo34WV hypothesis, identity and a stable functional state are still unknown. The smallest chemistry-relevant information assay would compare founder-conditioned **new active products** after matched resource exposure; it should not begin by assigning bits, mutation rates or intelligence to an unverified molecular formula.

## Dataset worth adding

The [Dillavou Dryad dataset](https://datadryad.org/dataset/doi%3A10.5061/dryad.8w9ghx3vx) lists a 15.76 MB data archive, README and related figure scripts. The README identifies training/testing inputs, free/clamped network states, capacitor gate voltages and learning intervals. It is particularly useful for separating local updates from supervision, and for checking that held-out evaluation actually withholds conditions. The presence of a field named TEST alone is not evidence of an independent test set. The repository was inspected; data/MATLAB replay was not downloaded or executed. These measurements do not constrain aqueous catalyst retention, reproduction or Mo34WV kinetics.

## Audit evidence and limits

`acquisition.json` retains successful and failed retrievals. The nonlinear-network primary article XML and VO2 author-manuscript PDF were downloaded and checked for document type; extracted text was read. The WO3 primary PDF/text already saved by the memory worker was reused. NiO was read in indexed primary full-text excerpts; fresh XML retrieval returned HTTP 500 and the author PDF returned HTTP 403, both retained. The mechanical primary article was directly readable. The independent mechanical-source child checked the distinction between gradient measurement and physical state updating.

No reviewed experiment demonstrates survival of learned organization through substantial replacement of its state-bearing material. That statement is bounded to these sources; it does not establish that such preservation is impossible, nor exclude other inorganic learning systems.

Skipped: new device experiments, the Dryad/MATLAB replay and an exhaustive follow-up search. Main risk: useful solid-state information functions may fail when translated into a renewing aqueous chemical network.
