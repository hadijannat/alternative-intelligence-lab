# Frozen RI-J numerical qualification

Purpose: test a tractable Coulomb approximation before any new parent calculation. This does not validate a compound, protonation state, functional complement or life. Existing failed parent attempts and small-reference results stay unchanged. No parent SCF is authorized by this protocol.

Cases fixed before execution: existing hypothetical MoO4(2-) in epsilon78.4 and epsilon1, and hypothetical MoO3 in epsilon78.4; external fixed Mo2O7(2-) coordinates from ICIQ item100/28779 as a held-out numerical challenge. The external geometry is from a different computational method and is not a verified minimum; no experimental held-out validation is claimed. All four cases run once, retaining failures even if the earlier cases fail. No auxiliary-basis selection or threshold tuning using these outcomes.

Use installed PySCF2.14.0, PBE/def2-SVP with Mo def2 ECP, spin0 trial, grid2, existing qualified BlockedPCM, C-PCM/SWIG order17/scale1.2/probe0. Coulomb reference is direct four-center evaluation with no cached ERI. Proposed RI-J uses fixed def2-universal-jfit and the installed two-pass df_jk.get_j; no DF.build, DF.loop, stored three-index tensor or HF exchange. Preserve existing ground-state-only solvent guards. A fresh persistent DF object is scoped to one fixed molecule. Explicitly reject unsupported calls, nonfinite/asymmetric density and changed geometry. Record cached metric factorization after every call and reject any result using the native regular-solve fallback. Native fallback could execute before rejection; this is not a claim that upstream fallback is prevented.

Compare direct and RI J on each initial density, a deterministic symmetric perturbation (seed7392016, Frobenius norm0.01) and converged reference density. Also test zero density, additivity of incremental densities and metric reuse. Fixed numerical screens: max absolute J difference<=1e-3Eh; absolute Coulomb energy difference<=1e-3Eh per Mo; finite symmetric J with asymmetry<=1e-10; zero/additivity error<=1e-9. Run one RI SCF per case (conv_tol1e-11,conv_tol_grad1e-7,max_cycle60). Three known direct total energies come from the unchanged earlier qualification; compute one new direct SCF for the external challenge. Require both reported convergence where newly executed, absolute total-energy difference<=1e-3Eh per Mo, direct-Fock orbital residual at the RI solution<=1e-3Eh, RI residual<=1e-5Eh and electron trace error<=1e-8. These are chosen numerical screening tolerances, not established chemical-accuracy or relative-energy guarantees. Save both operator errors and SCF errors separately; any exceeded criterion fails the case.

Exactly four sequential child runs, each capped at180seconds and sampled RSS2GiB by the existing supervisor with one-thread requests; no automatic retry. At most five SCFs (four RI,one direct). Save density/J arrays, actual runtime, failure and supervisor records. Fixed-density J timings are diagnostic only. Hash protocol, driver, wrapper, imported qualified solver, input records and installed DF/PCM code before launch and check them after. Run directory must be absent. Unit tests use synthetic/mocked inputs and cannot satisfy numerical acceptance. Review before launch; independent review recomputes saved errors afterward.

Source: https://pyscf.org/user/df.html recommends def2-universal-jfit for pure DFT and links its I/O-free J example; installed df_jk.py is the executable authority.
