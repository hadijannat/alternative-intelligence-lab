# Metric-only discrimination protocol

Scope: determine whether saved pass-1 perturbations reproduce coefficient differences with one fixed Coulomb metric, separately from repeated identical-RHS solves. This is numerical qualification work on the Mo36 parent surrogate, not evidence for the proposed Mo34WV species. Previous J nonpasses and the absolute 1e-10 threshold remain unchanged.

Saved stage-localization arrays contain neither original metric nor Cholesky factor. Existing vectors cannot establish solve residuals or conditioning. Build the same parent and auxiliary molecule using pinned qualified runtime and `addons.make_auxmol(..., 'def2-universal-jkfit')`; compare molecule and auxiliary fingerprints to the prior run. Execute only `auxmol.intor('int2c2e', hermi=1)`, then the frozen `memory.factor_inplace` and `memory.solve_checked`. No optimizer, three-index tensor, whole-J, SCF, or PCM calculation.

Persist original metric NPY before factorization; retain original metric in memory and factor a Fortran copy. Save metric and factor content hashes, comparing full factor bytes to prior recorded hash. A different factor means a different numerical realization; old/new rho differences cannot then isolate the prior solve. Each solve A1,A2,B,C reloads frozen b_A,b_A,b_B,b_C; save all answers and residuals. Compare A2 to A1 by exact equality and descriptive max/RMS; compare B,C to A1 and each to the original rho. No invented rho tolerance and no production stabilization.

Residual r=b-Ax is evaluated in float64 row blocks against the original metric. Report ||r||inf/(||A||inf ||x||inf+||b||inf), and max_i |r_i|/(|A||x|+|b|)_i. These are computed residual/backward-error diagnostics, not certified error bounds; residual cancellation remains possible. Require exact metric symmetry before using its infinity norm as the one norm. DPOCON estimates reciprocal one-norm condition from the lower Cholesky factor and original norm; it does not provide a certified bound. No response quotient is mislabeled as a condition number. Source: https://www.netlib.org/lapack/explore-html/d3/dfd/group__pocon_gaadb1e19663b71521d30b5b5bbe3091f8.html .

Before preparation, tests use analytic diagonal conditions 4 and 1e12, exact residual reconstruction, repeated solves, deliberately wrong answers, zero RHS, invalid metric and rejected approval/input-change gates. These qualify diagnostic calculations only. Parent run remains unexecuted pending independent root review binding preparation SHA and qualification artifacts. Launch is single-use (exclusive run-v1 creation); no automatic retry.

Caps: one child, one metric/factorization, four explicit solves plus LAPACK condition-estimator internal solves; 1000 s wall, 10 GiB sampled RSS. Two 19612-square float64 arrays use 6,154,088,704 bytes; potential LAPACK factor copy adds 3,077,044,352 bytes. Native memory overhead can exceed remaining headroom; guard failure is retained as incomplete, never relaxed. Host inspection: 38,654,705,664 B RAM, approximately 12 GiB available disk. Require metric payload plus 4 GiB disk reserve before building; metric is local evidence, not automatically publication material. No full inverse/eigendecomposition, dense absolute-matrix copy, or saved extra factor. Runtime controls OMP4, OMP_DYNAMIC FALSE, BLAS1 match prior run. Sampled RSS is not a hard OS bound.

Interpretation: exact identical-RHS repeats plus stable factor and reproduced perturbation effects support RHS sensitivity in this realization. Non-identical repeats expose solver/runtime variation. Conditioning and residuals inform whether later independently qualified stabilization is warranted. No result here clears SCF, identifies Mo34WV, validates seed dependence, or admits a life/intelligence complement.
