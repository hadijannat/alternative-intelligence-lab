# Frozen factor-only C-PCM/RI-J memory mechanics experiment

No SCF or parent-size arrays/launch. This is a new implementation experiment separate from the frozen JKFIT numerical campaign. It does not inherit numerical qualification merely by reusing its basis or equations.

Pin the installed PySCF df_jk.py/pcm.py, scipy Cholesky implementation and qualified BlockedPCM source before tests. Use a private function globals dictionary to specialize df_jk.get_j with a private scipy.linalg facade, leaving installed module globals/functions unmodified. Require float64 Fortran contiguous metric input, bounded finite checks in chunks of at most65536 elements, Cholesky overwrite enabled, check_finite disabled only after bounded validation, actual alias verification and read-only factor output. Catch factorization failure inside the facade and raise a distinct exception not derived from LinAlgError; this aborts the native catch/fallback path even if the overwritten metric is corrupted. The private regular-solve entry always rejects. Native two-pass integral contractions and optimizer construction remain unchanged.

C-PCM subclass uses row128 construction with Fortran S and in-place factorization, retains factor only and fixes AO block1. It preserves inherited ground-state/method guards and reset semantics; locally specialize only its solve call to the bounded validator. No process-global monkeypatch. Validate immutable/read-only factor storage plus finite RHS before check_finite=False solve; validate output. Scalar/vector and matrix validation must not create an N² Boolean array or copy a noncontiguous factor. Refuse unsupported layout rather than silently copying.

Tiny tests only: synthetic SPD and indefinite matrices up to64x64; finite/RHS/layout/read-only rejection; explicit injected factorization failure through the native local catch path proving regular fallback never executes; factor alias check; original global callable identity unchanged; one tiny He/sto-3g RI J operator comparison with fixed def2-universal-jkfit; one He six-point PCM density comparison against existing BlockedPCM. No SCF calls. Compare tiny operator/factor solve errors at1e-10, verify retained factor reuse and absent stored S; failed controls are expected rejections and retained. Actual parent performance, chemistry and RSS are untested.

Allocation accounting must retain4GiB scratch and32denseAO buffer allowances. Replace only demonstrated storage terms: one resident surface factor instead of S+factor/copy, AO block1 instead of8, one RI metric factor when actual Fortran aliasing is demonstrated. Keep row-temporary allowance, bounded finite-check allowance and nuclear-block allowance. State all unbounded native scratch/allocator/integral/SCF costs; no certified peak RSS claim or parent admission follows from arithmetic.
